# MeshCentral Bulk Script Runner 0.1.0

Предварительная версия. Поддерживает выбор устройств текущего домена, фильтрацию по группе, имени, IP, описанию и тегам (AND/OR), ручной выбор и хранение шаблонов. Доступ к данным и шаблонам ограничен полным администратором текущего домена. Шаблоны сохраняются в `meshcentral-data/bulkrunner/presets.json`; каждый шаблон привязан к домену. Каталог `history` создаётся при запуске.

**Запуск скриптов отключён на клиенте и сервере.** В этой версии ещё нет подтверждённого протокола исполнения, независимого сбора stdout/stderr и exit code, прерывания процесса, очереди, истории, экспорта и изменения тегов. Не используйте версию 0.1 как готовое решение для массового исполнения. Встроенная команда MeshCentral сама по себе не подтверждает указанные свойства. Удаление временных файлов невозможно гарантировать при принудительном завершении ОС или отключении питания.

## Установка для разработки

MeshCentral загружает каталог и серверный файл по `shortName`. Скопируйте содержимое этого каталога в `meshcentral-data/plugins/bulkrunner/` и зарегистрируйте плагин в MeshCentral согласно способу локальной установки вашей версии. Метаданные не содержат опубликованных URL для установки из сети. Перезапустите сервер и откройте интерфейс под полным администратором. Кнопка Bulk Script Runner появляется в правом нижнем углу. Требуются Node.js 18+ и MeshCentral 1.1.0+; совместимость с работающим сервером и различными версиями MeshCentral ещё требует проверки.

## Проверка

`node tests/basic.js` — проверка хранения, изоляции доменов и отказа в неподдерживаемом запуске с имитацией интерфейсов MeshCentral.
