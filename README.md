# MeshCentral Bulk Script Runner 0.1.6

Экспериментальный плагин для MeshCentral 1.1.0+ и Node.js 18+. Установка через менеджер плагинов:

`https://raw.githubusercontent.com/Sokol549/MeshCentral-BulkScriptRunner/main/config.json`

Поддерживается Windows PowerShell: выбор устройств и фильтры, шаблоны, очередь, таймаут и отмена, раздельные stdout/stderr, коды завершения, теги успешных устройств, снятие тега, история и экспорт JSON/CSV. Запуск осуществляется с правами службы MeshAgent. Для устройства требуются права запуска команд; для тегов дополнительно требуется право управления устройством. Работает только для полного администратора сайта. При установке код агента включается в MeshCore и может распространяться на подключённые агенты.

Версия предварительная. Скрипт ограничен 32768 байтами и размером сообщения агенту; каждый поток ограничен 4000 символами (в результате указывается `truncated`). Многострочные и большие скрипты передаются через stdin, без записи и удаления временных файлов на устройстве. Linux отключён до отдельной реализации и проверки. При потере связи результат помечается неизвестным, дальнейшая отправка останавливается. После перезапуска сервера незавершённые задания не запускаются повторно. Завершение дочерних процессов скрипта не гарантируется: таймаут и отмена завершают основной процесс; неподтверждённая остановка помечается неизвестной. Полный цикл через установленный плагин ещё не проверен на работающем сервере.

Данные хранятся в `meshcentral-data/bulkrunner/`. Скрипты и результаты могут содержать конфиденциальные данные: ограничьте доступ к этому каталогу.

Исполнитель Windows проверен на компьютере sokol в среде MeshAgent через Terminal: раздельный вывод и код 3, отмена тестового процесса, скрипт около 30 КБ с кодом 8. Серверный маршрут, теги, сохранение и очередь на 100 устройствах проверены локальными тестами с имитацией MeshCentral.
