# MeshCentral Bulk Script Runner 0.1.1

Экспериментальный плагин для MeshCentral 1.1.0+ и Node.js 18+. Установка через менеджер плагинов:

`https://raw.githubusercontent.com/Sokol549/MeshCentral-BulkScriptRunner/main/config.json`

Версия 0.1.1 поддерживает выбор устройств и фильтры, шаблоны, запуск PowerShell/Bash, очередь, отмену, таймаут, журнал результатов и экспорт JSON/CSV. Запуск выполняется с правами службы MeshAgent. Требуются права запуска команд на каждом устройстве и полный администратор сервера. Код агента включается в MeshCore при установке и может распространяться на подключённые агенты.

Версия предварительная: поддерживаются скрипты до 6000 байт, выходные потоки ограничены 4000 символами каждый (результат содержит признак `truncated`). Большие скрипты через временные файлы, теги и массовое снятие тегов пока не реализованы. Процент успешных устройств, автоматическое обновление таблицы после закрытия сессии, восстановление активной очереди после перезапуска и повторная сверка результатов ещё не реализованы. При обрыве связи результат помечается неизвестным и дальнейшая отправка останавливается. Завершение дочерних процессов скрипта не гарантируется; таймаут и отмена завершают основной процесс, а неподтверждённая остановка помечается неизвестной. Не используйте предварительную версию для задач, где эти ограничения неприемлемы.

Данные хранятся в `meshcentral-data/bulkrunner/`. Скрипты и результаты могут содержать конфиденциальные данные: ограничьте доступ к этому каталогу. Никакие тесты в комплекте не выполняют удалённые команды автоматически.

Исполнитель Windows проверен на компьютере sokol в среде MeshAgent через Terminal: получены stdout, stderr и код 3, проверена остановка тестового процесса. Маршрут сервера и пул проверены локальными тестами с имитацией MeshCentral. Работа всей цепочки на сервере и Linux-агенте ещё требует проверки.
