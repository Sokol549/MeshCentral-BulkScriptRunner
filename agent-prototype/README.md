# Экспериментальный код

Этот модуль не подключён к MeshCentral и не предназначен для установки. Его нельзя помещать в `modules_meshcore` до проверки совместимости с настоящим MeshAgent и реализации подтверждённого завершения дерева процессов, корректной передачи больших скриптов и вывода, восстановления при потере связи и интеграции с сервером. Модуль пока не реализует полное ТЗ и проверен только с имитацией агентского API. Локальная проверка PowerShell использует адаптер Node.js и не является проверкой MeshAgent.
